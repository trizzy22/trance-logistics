# Trance Logistics Image Assets

This directory contains all image assets for the Trance Logistics website.

## Required Images

### 1. **truck-hero.jpg** (Hero Section)
- **Location**: `assets/images/truck-hero.jpg`
- **Dimensions**: 1920 x 1200px minimum (16:9 aspect ratio)
- **Purpose**: Background image for the homepage hero section
- **Recommended**: Professional photo of the Trance Logistics delivery truck
- **Quality**: High-resolution, well-lit, professional photography

### 2. **team-group.jpg** (About & Homepage Team Section)
- **Location**: `assets/images/team-group.jpg`
- **Dimensions**: 1600 x 900px minimum (16:9 aspect ratio)
- **Purpose**: Team photo used on homepage and about page
- **Recommended**: Professional group photo of the Trance Logistics team
- **Quality**: High-resolution, professional group portrait

## How to Add Your Images

1. Export your photos from the images provided:
   - Image 1: Truck with Trance Logistics branding
   - Image 2: Team photo at headquarters

2. Optimize for web:
   - Compress using TinyPNG or similar tool
   - Keep file sizes under 500KB for web performance
   - Use JPEG format for photographs

3. Upload to this directory with the filenames above

4. The website will automatically integrate them into:
   - Homepage hero section (truck-hero.jpg)
   - Homepage team section (team-group.jpg)
   - About page team section (team-group.jpg)

## Image Optimization Tips

- Use progressive JPEG format for better loading
- Set appropriate alt text (already configured in HTML)
- Consider adding a WebP version for modern browsers
- Ensure images meet WCAG accessibility standards
